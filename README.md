## Задание: Подбор персонала

#### Необходимо разработать приложение для подбора персонала на предприятие. Программа должна позволять вводить основные данные о работниках, а также указывать должность, на которую они поступают. Для выбора должности необходимо использовать выпадающий список (Spinner). Список должностей составляется на ваше усмотрение в зависимости от сферы трудовой деятельности, придуманной вами. При нажатии на кнопку «Сохранить» новый работник добавляется в список, а поля ввода очищаются.

#### В списке работников данные имени и фамилии должны отображаться крупным шрифтом друг под другом, а должность и возраст — мелким шрифтом, также друг под другом. Работников можно удалять, нажав на элемент списка с работником, которого нужно удалить. При выборе пункта меню «Exit» приложение закрывается.

## Для работы приложения необходимо создать:

### На экране:

1. Toolbar с заголовком «Подбор персонала».

2. Поля ввода: имени, фамилии, возраста и должности (для выбора должности использовать Spinner).

3. Кнопку «Сохранить».

4. ListView, в который будут помещены созданные работники.

5. Меню с одним пунктом «Exit».

### *** Необязательно, но желательно (усложненный уровень).

В приложении должна быть возможность сортировать список по должности и изменять отображаемый список работников в зависимости от выбранной должности. Для этого в Toolbar необходимо добавить Spinner, который будет включать список основных должностей. Например, если в списке сохранены два инженера, три конструктора и четыре энергетика, то при выборе «Конструктор» в Spinner список будет фильтроваться и отображаться только три конструктора.
