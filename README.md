# Приложение «Мои заметки»

## Задание

Необходимо создать приложение, которое реализует список заметок на основе элемента RecyclerView. На экране приложения должен быть список, в котором каждая ячейка включает порядковый номер заметки, текст заметки, CheckBox для отметки выполненной заметки и поле времени и даты создания заметки. Для этого необходимо создать класс модели с указанными полями. Выше списка располагается поле ввода текста заметки и кнопка для добавления заметки в список.

Вся конструкция приложения должна быть реализована на основе фрагмента.

## Для работы приложения необходимо создать:

### На экране:

1. Toolbar с заголовком «Мои заметки».
2. Поле ввода заметки.
3. Кнопка «Добавить».
4. RecyclerView для отображения списка заметок.
5. Пункт меню «Exit» для выхода из приложения.

*** Необязательно, но желательно (усложненный уровень).

Реализовать сохранение созданных заметок в базу данных и их получение из базы данных при запуске приложения.
